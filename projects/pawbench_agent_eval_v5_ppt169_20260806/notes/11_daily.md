# 11 任务 ↔ 日常工作能力 - 演讲备注

**时长建议**: 60 秒

**讲解要点**:
- 日常 7 类使用场景中，6 类在 PawBench 都有强匹配任务，走完全相同的「执行→采集→评分→汇总」链路。
- 表格逐行简述：邮件处理（T016 混合评分）、通讯录/CRM（T026/027）、内部新闻/资讯（T025 RSS 筛选摘要）、Excel/表格（T140 修复 xlsx 缺值）、文档 PDF（T055/T058 纯 LLM 评判）、代码处理（T064 Playwright E2E）、Skill 创建/使用（T076-T094、SkillsBench T126-T140）。
- 强调：这些任务均为 hybrid 评分（自动检查 + LLM 评判），与日常使用 OpenClaw 处理邮件/表格/文档/代码/Skill 的能力高度对应，评测结果可直接指导工作流选型。
