# 内网离线环境 PawBench 评测操作手册

## 背景

公司 LLM 环境部署在内网，PawBench 评测需要在外网完成准备工作（构建镜像、下载依赖），再将产物传输到内网服务器执行评测。本手册适用场景：

- 内网服务器无法直接访问 PyPI、Docker Hub 等外网资源
- 内外网 glibc、Python 版本需保持一致
- 使用 OpenClaw 作为 agent harness

## 整体流程

```
外网（有网络）                   内网（无网络）
  │                                │
  ├─ 1. 准备 UBI8 容器             │
  ├─ 2. 下载 standalone Python      │
  ├─ 3. 下载 Python wheel 依赖      │
  ├─ 4. 构建 OpenClaw 镜像          │
  │                                │
  └─ 打包传输 ──────────────────→  ├─ 5. 导入镜像 & 解压 Python
                                   ├─ 6. 创建虚拟环境 & 安装依赖
                                   ├─ 7. 配置 .env
                                   └─ 8. 运行评测
```

## 环境确认

### 内网服务器

```bash
# 查看操作系统与 glibc 版本
cat /etc/os-release
ldd --version
```

示例输出：
```
Kylin Linux Advanced Server V10
glibc 2.28
```

### 外网准备机

使用与内网 glibc 版本一致的容器镜像。建议使用 Red Hat UBI8（glibc 2.28），与 Kylin V10 兼容：

```bash
docker pull registry.access.redhat.com/ubi8/ubi:latest
```

---

## 第 1 步：在外网准备 Python 环境和依赖

### 1.1 启动 UBI8 容器并进入

```bash
docker run -it --rm \
  -v /path/to/PawBench:/workspace/PawBench \
  registry.access.redhat.com/ubi8/ubi:latest \
  bash
```

> 将 `/path/to/PawBench` 替换为实际 PawBench 项目所在路径。

### 1.2 安装基础工具

```bash
# UBI8 基础镜像较精简，先安装必要工具
yum install -y tar gzip wget curl findutils
```

### 1.3 下载 standalone Python

从 [python-build-standalone](https://github.com/astral-sh/python-build-standalone/releases) 下载与内网目标版本一致的 Python。

确保内外网 Python 版本一致。例如下载 **cpython-3.11.15+20260610-x86_64-unknown-linux-gnu-install_only.tar.gz**：

```bash
cd /opt
wget https://github.com/astral-sh/python-build-standalone/releases/download/20260610/cpython-3.11.15%2B20260610-x86_64-unknown-linux-gnu-install_only.tar.gz
tar -xzf cpython-3.11.15+20260610-x86_64-unknown-linux-gnu-install_only.tar.gz -C /opt/python311
```

### 1.4 设置 Python 环境变量

```bash
export PATH=/opt/python311/install/bin:$PATH
export LD_LIBRARY_PATH=/opt/python311/install/lib:$LD_LIBRARY_PATH
python3 --version   # 确认版本一致
```

### 1.5 下载 PawBench 的 Python 依赖

```bash
cd /workspace/PawBench

# 可选：使用国内 PyPI 镜像加速
pip3 config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

# 创建 wheelhouse 目录，仅下载二进制 wheel（不安装）
mkdir -p wheelhouse311
pip3 download --only-binary=:all: -r requirements.txt -d wheelhouse311
```

> 如果某些依赖没有预编译的 wheel，可去掉 `--only-binary=:all:` 让 pip 下载源码包。

---

## 第 2 步：在外网构建 OpenClaw 镜像

### 2.1 准备构建上下文

确保 PawBench 项目完整，Dockerfile 使用项目内置的 `docker/Dockerfile.pawbench-openclaw`。

### 2.2 构建镜像

```bash
cd /workspace/PawBench
docker build -f docker/Dockerfile.pawbench-openclaw -t pawbench-openclaw:4.24-1 .
```

> 镜像标签 `4.24-1` 对应 OpenClaw 2026.4.24 版本。如果需要新版本 OpenClaw，修改 Dockerfile 中的 `OPENCLAW_VERSION` ARG 值，并调整镜像标签。

### 2.3 保存镜像为 tar 包

```bash
docker save -o pawbench-openclaw_4.24-1.tar pawbench-openclaw:4.24-1
```

---

## 第 3 步：打包并传输到内网

需要传输到内网服务器的文件清单：

| 文件/目录 | 说明 |
|-----------|------|
| `PawBench/` 完整项目目录 | 包含 `run_bench.py`、任务数据等 |
| `pawbench-openclaw_4.24-1.tar` | OpenClaw Docker 镜像 |
| `wheelhouse311/` | Python wheel 包目录 |
| `cpython-3.11.15+20260610-x86_64-unknown-linux-gnu-install_only.tar.gz` | standalone Python 包 |

---

## 第 4 步：在内网服务器搭建环境

### 4.1 导入 Docker 镜像

```bash
docker load -i pawbench-openclaw_4.24-1.tar
docker images | grep pawbench-openclaw   # 确认导入成功
```

### 4.2 解压 standalone Python

```bash
tar -xzf cpython-3.11.15+20260610-x86_64-unknown-linux-gnu-install_only.tar.gz -C /opt/python311
export PATH=/opt/python311/install/bin:$PATH
python3 --version
```

可将上述 `export` 写入 `~/.bashrc` 以便持久化。

### 4.3 创建 Python 虚拟环境

```bash
cd /path/to/PawBench
python3 -m venv venv
source venv/bin/activate
```

### 4.4 安装 PawBench 依赖（离线模式）

```bash
pip install --no-index --find-links=wheelhouse311 -r requirements.txt
```

> `--no-index` 禁止 pip 访问网络，`--find-links` 指向本地 wheel 目录。

### 4.5 创建结果目录

```bash
mkdir -p results
```

---

## 第 5 步：配置 `.env`

在 PawBench 项目根目录创建 `.env` 文件：

```bash
cat > .env <<'EOF'
# LLM 模型配置
OPENAI_API_KEY=deepseek-v4-test
OPENAI_BASE_URL=http://10.18.0.104:30111/v1
OPENAI_MODEL=deepseek-v4-flash-normal

# Judge 评分模型配置
JUDGE_API_KEY=deepseek-v4-test
JUDGE_BASE_URL=http://10.18.0.104:30111/v1
JUDGE_MODEL=deepseek-v4-flash-normal
EOF
```

> 以上 `10.18.0.104` 和 API Key 仅供参考，根据实际内网 LLM 服务地址修改。

---

## 第 6 步：运行评测

### 基础用法

```bash
source venv/bin/activate
python run_bench.py \
  --agents openclaw \
  --docker-image pawbench-openclaw:4.24-1 \
  --model deepseek-v4-flash-normal \
  --concurrency 10 \
  --verbose \
  --save-workspace
```

### 参数说明

| 参数 | 说明 |
|------|------|
| `--agents openclaw` | 使用 OpenClaw harness |
| `--docker-image pawbench-openclaw:4.24-1` | 指定上一步构建的 Docker 镜像 |
| `--model deepseek-v4-flash-normal` | 指定模型名称，会覆盖 `.env` 中的 `OPENAI_MODEL` |
| `--concurrency 10` | 并发启动 10 个容器同时评测 |
| `--verbose` | 输出详细日志 |
| `--save-workspace` | 保存每个任务的 agent workspace，便于事后复盘 |

### 指定任务

如需仅评测特定任务，加 `--tasks` 参数（多个任务用空格分隔）：

```bash
python run_bench.py \
  --agents openclaw \
  --docker-image pawbench-openclaw:4.24-1 \
  --model deepseek-v4-flash-normal \
  --tasks T053 T054 T055 \
  --concurrency 5 \
  --verbose \
  --save-workspace
```

### 查看完整参数

```bash
python run_bench.py --help
```

## 常见问题

### Q1：运行 `run_bench.py` 时报错找不到 Docker

确保 Docker 已安装且当前用户有权限运行 Docker：

```bash
docker info
```

如果当前用户不在 docker 组，需用 `sudo` 或添加到 docker 组：

```bash
sudo usermod -aG docker $USER
# 重新登录后生效
```

### Q2：内网 Python 版本与 standalone 包不匹配

重新在外网下载与内网一致版本的 standalone Python，重新走第 1~3 步。

### Q3：wheelhouse 中缺少某个依赖

在外网容器中手动下载缺失的包：

```bash
pip3 download --only-binary=:all: <package-name> -d wheelhouse311
```

然后将 `wheelhouse311` 重新传输到内网。

### Q4：Docker 版本较低（如 Docker 19）时容器无法正常工作

Docker 19 及部分低版本需要额外 `seccomp` 配置，否则 `run_bench.py` 启动的容器会异常退出。

在 `pawbench/envs/docker.py` 的 `start()` 方法中找到 `cmd` 列表，加入：

```python
cmd.extend(["--security-opt", "seccomp=unconfined"])
```

修改后类似：

```python
def start(self, image_name, cmd_args, **kwargs):
    cmd = ["docker", "run", "-d", ...]
    cmd.extend(["--security-opt", "seccomp=unconfined"])   # 低版本 Docker 必加
    ...
```

### Q5：Docker 构建时 APT 源或 pip 源下载慢

在 Dockerfile 中修改为国内镜像源（Dockerfile 已内置 `docker/debian.sources` 和阿里云 PyPI 镜像配置），参考：

```dockerfile
# pip 国内源设置（位于 Dockerfile 中）
RUN pip3 install --no-cache-dir --break-system-packages \
    -i https://mirrors.aliyun.com/pypi/simple/ \
    -r /opt/copawbench/requirements.txt
```

### Q5：内网服务器没有 GPU / 显存不足

PawBench 评测由 Docker 容器内 agent 调用远端 LLM API（配置在 `.env`），内网服务器本身不需要 GPU，仅需足够的内存和磁盘空间。建议内存 ≥ 32 GB，空闲磁盘 ≥ 100 GB（用于并发容器工作区）。
