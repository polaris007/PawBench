# 04 主流 Agent 评测方法论全景 - 演讲备注

**时长建议**: 120 秒（新增方法论页，重点讲解）

**讲解要点**:
- 这一页梳理主流评测方法论六大范式，回答"怎么评"的问题。主流评测体系普遍是多种范式的混合实践。
- ① 最终状态评估：确定性后端 + 最终产物/状态比对。可复现、有标准答案，但构建确定性环境工程量大。代表：τ-bench、τ²-bench、AppWorld。
- ② 轨迹评估：黄金轨迹对齐，或用 LLM 评判轨迹质量。可定位失败步骤，但多路径正确性难以定义。代表：LangSmith、AgentEvals。
- ③ LLM-as-a-Judge：强模型 + Rubric 细则评分。可扩展、适合开放式任务，但需验证评判一致性。
- ④ 逐步评估：对每一步独立校验（工具选择、参数、输出）。错误定位精确，但忽略步骤间依赖。代表：Arize Phoenix、DeepEval。
- ⑤ pass@k 采样：k 次运行的成功率/全成功一致性。更诚实反映随机性，但成本随 k 上升。代表：Claw-Eval、CI 实践。
- ⑥ 沙箱环境模拟：Docker 隔离 + 离线快照可复现。真实性与可控性的折中，环境构建成本高。代表：GAIA、WebArena、OSWorld。
- 来源：ACL 2026《A Survey on Evaluation of LLM-based Agents》等公开文献与社区实践。
