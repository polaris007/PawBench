# 工具对比表

| 工具 | 定位 | 评测对象 | 是否评测完整 Agent 系统 | 内网运行能力 | 数据/任务依赖公网 | 扩展能力 | 资料/生态 | 优势 | 劣势 | 适用场景 |
|---|---|---|---|---|---|---|---|---|---|---|
| PawBench | Agent Benchmark 平台 | Agent Runtime + Model + Task | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐（部分任务需改造） | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 基于 OpenJudge，Task/Judge/Runner 解耦；支持多 Agent；适合企业自定义任务；国产生态 | 需要理解 OpenJudge 架构；公开标准榜单影响力仍在增长 | 企业 Agent 评测平台首选 |
| OpenJudge | Agent Evaluation Framework | Judge / Score / Reward | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 可自定义 Judge；适合作为企业评测基础设施 | 本身不是完整 Benchmark，需要准备任务 | 企业内部评测底座 |
| WildClawBench | Agent Benchmark Dataset | 长流程 Agent | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 任务质量高；支持 OpenClaw、Claude Code、Codex 等 Harness；关注长任务能力 | 部分任务依赖互联网，需要离线改造 | 行业 Benchmark、能力验证 |
| SkillsBench | Skill 能力 Benchmark | Skill / Memory / Knowledge 使用能力 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 可以量化 Skill、Memory、知识库价值 | 不是完整 Agent Benchmark | Skill 体系评估 |
| PinchBench | Coding Agent Benchmark | Coding Agent | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐ | Coding 场景明确 | 范围偏窄 | Coding Agent |
| AgentBench | 学术 Benchmark | LLM-as-Agent | ⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 学术影响力强；环境设计经典；适合模型比较 | 更偏底层 LLM Agent，不适合评估完整 OpenClaw 系统 | 学术研究、模型比较 |
| GAIA | General Agent Benchmark | 通用 Agent | ⭐⭐⭐ | ⭐⭐ | ⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐⭐ | 综合任务强，行业认可度高 | 数据和外部环境依赖明显 | Agent 能力对标 |
| SWE-bench | Coding Benchmark | 软件修复 Agent | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | Coding Agent 标杆 | 只覆盖代码修复 | 软件开发 Agent |
| DeepEval | Evaluation Framework | LLM / RAG / Agent | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 成熟；支持 CI；企业使用广泛 | 不提供完整 Agent 任务体系 | 企业质量回归 |
| Promptfoo | Prompt/LLM Eval Framework | Prompt + Model | ⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 简单成熟；适合 Prompt 和模型 A/B 测试 | 不适合作完整 Agent Benchmark | Prompt 调优 |
