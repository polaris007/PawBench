# 06 PawBench 的优势 - 演讲备注

**时长建议**: 60 秒

**讲解要点**:
- 四大核心优势：完整 Agent 评测（Model×Harness×Task 同时评估）、内网安全运行（Docker 数据不出网）、Model×Harness 交叉评测（行业首创解耦设计）、开源可扩展（OpenJudge 生态、Apache 2.0、AgentScope 维护）。
- 差异化：非纯 LLM 榜单（区别于 GAIA/AgentBench/PinchBench 等依赖公网的方案）、非纯 Skill 评测（覆盖 7 大原子能力含完整流程）。
- 结论条：唯一在「完整 Agent」「内网部署」「可扩展」三项同时 ★★★★★ 的方案。
