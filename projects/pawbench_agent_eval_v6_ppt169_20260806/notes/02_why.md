# 02 为什么需要 Agent 评测 - 演讲备注

**时长建议**: 60 秒

**讲解要点**:
- 痛点一：升级效果无法量化。模型或 Agent 升级后，过去靠人工挑几个案例来"感觉"好坏，缺乏客观数据，形成不了技术决策依据。PawBench 用 150 道标准化任务 + 自动评分引擎，跑完即出分、版本间可横向对比。
- 痛点二：现有方案局限。通用 LLM 榜单不测工具调用与 Agent 行为；学术 Benchmark 依赖公网，无法内网部署。PawBench 开源 + Docker 沙箱隔离，数据不出网、零外部依赖。
- 收束：需要一个标准化、可复现、内网可用的方案 → PawBench 带来三大价值：量化升级效果、精准定位短板、内网安全运行。

**过渡语**:
先看看市面上主流方案长什么样，PawBench 和它们有什么区别。
